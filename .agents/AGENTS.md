# Project Rules

- **Git Commits & Pushes**: Do NOT stage, commit, or push any changes to any git branches automatically. Only stage, commit, or push changes when the USER explicitly requests or commands you to do so.

- **Domain Rules**: Before modifying any academic, attendance, timetable, examination, fee, student, faculty, library, placement, or administrative functionality, read `apps/admin-web/docs/COLLEGE_DOMAIN_RULES.md` first. The domain rules document is the project's authoritative college-specific source of truth. Never silently change or override those rules.
